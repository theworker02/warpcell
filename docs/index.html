Overview

Warp CSV/TSV cell tables for quick inspection and cleanup. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/warpcell.git
cd warpcell
node src/cli.js --help
node --test

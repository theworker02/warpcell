# warpcell

Warp CSV/TSV cell tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/warpcell/

## Install / run

```bash
git clone https://github.com/theworker02/warpcell.git
cd warpcell
node src/cli.js
node --test
```
